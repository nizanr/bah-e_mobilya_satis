# Gerçek hata raporu şablonu

Bu dosya 100 hata bulunduğu iddiası değildir. Her gerçek hata için GitHub issue açılabilir.

- Kimlik / başlık:
- Tarih, test eden kişi, commit:
- İlgili test senaryosu:
- Ortam: cihaz, tarayıcı, sürüm, ekran boyutu:
- Önkoşullar / kullanılan rol:
- Tekrarlama adımları:
- Beklenen sonuç:
- Gerçek sonuç:
- Kanıt: ekran görüntüsü, temizlenmiş hata çıktısı:
- Önem: kritik / yüksek / orta / düşük:
- Durum: açık / düzeltildi / tekrar test edildi:
- Düzeltme commit'i / tekrar test sonucu:

Gerçek kart, şifre, API anahtarı, oturum çerezi veya kişisel fotoğraf eklemeyin. Aynı kök nedenin tekrarını bağlantılı senaryo olarak kaydedin.
